# NEXORA AI Agent — задача для анализа

Это существующий рабочий проект NEXORA AI Agent.

Цель проекта:
сделать NEXORA полноценным AI Coding Agent, способным самостоятельно создавать полноценные Telegram-боты по описанию пользователя.

ВАЖНО:

Не переписывать проект с нуля.

Не удалять существующий рабочий функционал.

Не менять архитектуру без необходимости.

Сначала изучить весь проект и определить:
- что уже работает;
- что можно оставить;
- что необходимо изменить;
- что необходимо добавить;
- что является лишним;
- что потенциально мешает созданию полноценных Telegram-ботов.

Особенно проверить:

1. Planner
2. Router
3. Providers
4. Executor
5. Sandbox
6. Repair
7. Project Context
8. Tools
9. Работа с workspace
10. Ограничения размера AI-ответов
11. Создание нескольких файлов
12. requirements.txt
13. Установку зависимостей
14. Тестирование Python-кода
15. Исправление ошибок
16. Безопасность BOT_TOKEN и других секретов

Конечный результат:

Пользователь должен иметь возможность написать NEXORA:

"Создай Telegram-бота с /start, кнопками, обработкой сообщений и базой данных"

и NEXORA должна самостоятельно:

- спроектировать структуру;
- создать необходимые файлы;
- создать requirements.txt;
- установить зависимости;
- написать код;
- протестировать его;
- найти ошибки;
- исправить их;
- повторно протестировать.

Главное требование:

НЕ ПЕРЕПИСЫВАТЬ ЛИШНЕЕ.

Сохранять существующий код, если он уже выполняет нужную функцию.

Если изменение можно сделать в одном месте — не меняй пять файлов.

Перед внесением изменений сначала провести полный анализ проекта.

Также отдельно указать, какие файлы необходимо:
- оставить;
- изменить;
- добавить;
- удалить (если действительно необходимо).

Удаление допускается только после объяснения причины.

API-ключи и реальные секреты в проекте отсутствуют/не должны попадать в архив.
